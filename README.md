# Abartılı Motivasyon Koçu

## Bu Proje Nedir?

Bu, insanlığın en büyük sorununu çözmek için tasarlanmış devrim niteliğinde bir yazılımdır: **Motivasyon eksikliği**. 

Artık "bugün hiçbir şey yapmak istemiyorum" demek yok. Bu koç, seni o kadar abartılı bir şekilde motive edecek ki, ya da tam tersi, tamamen çökeceksin. İki seçenek de kazanç.

## Özellikler

- Gerçekten çalışıyor (Python 3 ile)
- Sonsuz motivasyon döngüsü
- Absürt tavsiyeler
- Hiçbir işe yaramaz ama eğlencelidir
- Bilimsel olarak kanıtlanmamıştır (kanıtlamak istemedik)

## Nasıl Kullanılır?

```bash
python motivasyon_kocu.py
```

Sonra ne hissettiğini söyle, koç gerisini halletsin. Dikkat: Aşırı kullanım halinde gerçek hayattan kopabilirsin.
